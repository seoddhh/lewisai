# 서울로 코스 생성 에이전트 develop을 위한 로드맵 계획 문서(07/15 멘토링 이후 작성)

1. 운영 시간 기반 장소 추천 데이터 고도화 및 사용자 입장에서 시간 선택 및 자연어 입력 task 처리 가능하도록. 

2. 칩 선택에서 시간대를 설정하면 해당 시간대에 맞게 장소의 운영시간 정보와 근처 식당 정보등을 고려하여 스케줄 형태로 코스를 고도화.

3. 혼잡도 정보를 요청 하지 않아도 응답에 계속 주입하기 때문에 레이턴시가 느려지는점을 개선.

4. 지금까지 테스트한 결과 AI멘트는 다르게 나오지만 사용자의 칩 선택에 따른 장소 분기가 제대로 이루어지지 않는다 ex)10-20대 와 40-50이 선호하는 장소생성 로직을 설계하여 더 개인화된 추천 코스로 설계

5. 한국인/외국인 관광객의 입력 분기를 다르게 하도록 수정 에이전트 코스 생성시 로컬/관광객으로 입력 버튼 클릭후 자연어 입력 처리
    - if 관광객 입력 처리라면 외국인 관광객에 맞게 해당 장소를 처음 방문하는 시각으로 장소 정보 재구성(영어 출력 프롬프트 구성)
